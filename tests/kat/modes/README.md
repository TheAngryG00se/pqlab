Тесты читают примеры приложения F для всех трёх размеров ключа AES.
CBC API всегда добавляет PKCS#7: официальные четыре блока сверяются как
префикс; дополнительный блок проверяется отдельно свойствами дополнения.
CTR проверяется также на неполном последнем блоке как префикс официального
примера. Эти проверки не заменяют исходные ожидаемые значения.
