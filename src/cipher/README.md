# Блочные шифры участника 3

Реализация AES-128/192/256: [AES.md](AES.md). Объект реализует существующий
`pq::BlockCipher`; для создания по каноническому имени модуль предоставляет
`pq::cipher::register_algorithms(Registry&)` в `register.hpp`.

Глобальный реестр и производственная сборка принадлежат участнику 4.
В этой ветке они не меняются: тесты компилируют исходники напрямую,
проверяя собственный локальный реестр. `CMakeLists.txt` модуля подготовлен
для последующего подключения через `add_subdirectory(cipher)`.

Все режимы по умолчанию получают шифр с полным числом раундов.
Сокращать число раундов разрешено только из `analysis/`.
